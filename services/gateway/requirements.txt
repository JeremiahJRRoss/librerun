# The LibreRun gateway image (blueprint S4a).
#
# Deliberately NOT the backend's list. This process holds the provider
# credentials and nothing else: no JWT signing, no report rendering, no
# vector store, no web search. What it does share is the chassis's
# redaction and export walkers, which is why presidio, spacy and the
# OTLP exporter appear here — the gateway's own spans and log lines are
# walked exactly like the backend's, and the outbound redaction is the
# same pii_service the intake pipeline runs.

# an extra is how the proxy and its Enterprise code come in (C-19 to
# C-21), and a new release is a reviewed relock
